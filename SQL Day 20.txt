Window Functions :
mainly used to find the rows.
Types of window functions:
1. ranking function
	row_number
	rank()
	dense_rank()
	ntile()
2. aggregrate function:
	avg()
	mx()
	min()
	count()
	sum()
3. offset function:
	first_value()
	lag()
	lead()
Syntax of window function:
select columnlist,functionname over() as alias name from tablename;
-> window function is represented by over()
i. partition by -  it is used to divide data into a group based on column.
ii. order by - to sort the data into a order based on column.
